# Evaluation Results & Visualizations

This directory contains experimental outputs, benchmark logs, and visual demonstrations generated by the pipeline.

## Generated Artifacts

- **`kalman_occlusion_analysis.png`**:
  Four-quadrant verification plot detailing the kinematic state estimation during temporary detector occlusions. Shows ground truth trajectory, detector dropouts, Kalman filter continuous state estimation, bounded localization error (< 1.8 px), and covariance matrix $P$ uncertainty bounds ($\pm 2\sigma$).
- **`offline_tracked_demo.mp4`**:
  Rendered video demonstration of the Kalman + Hungarian multi-object tracker running on KITTI sequential frames at 40+ FPS, featuring track IDs, class badges, velocity vectors, and trajectory history trails.
- **`motmetrics_summary.csv` & `motmetrics_summary.json`**:
  CLEAR MOT evaluation benchmark scores (MOTA, MOTP, IDF1, MT, ML, FP, FN, ID Switches).
- **`benchmark_fps.json`**:
  Runtime latency and throughput comparison between PyTorch (`.pt`) and ONNX Runtime (`.onnx`).
